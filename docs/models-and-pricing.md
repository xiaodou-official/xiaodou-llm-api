# 模型与价格

> 适用版本：v1.0.0 ｜ 更新：2026-11-22 ｜ 返回 [README](../README.md)

## 1. 一句话口径

- **国产模型**：零售价 = 厂商公开挂牌价 **×0.5**（5 折）。
- **海外模型**：零售价 = 官方 / OpenRouter 公开价 **×1.25**（不是折扣）。
- 计价单位：**人民币 / 100 万 tokens**，输入与输出分开算。
- 最终扣费：以控制台「模型广场」公示价与「日志」页实际 tokens 为准。

## 3. 一次请求怎么算钱

```
费用 = 输入 tokens × 输入单价 + 输出 tokens × 输出单价
```

举例：`glm-5.3` 输入 2,000 tokens、输出 1,000 tokens：

```
2000 / 1,000,000 × 2.08 + 1000 / 1,000,000 × 7.28
= 0.00416 + 0.00728
= ¥0.01144
```

便宜的模型跑长文本、贵的模型跑难任务，是控制成本最直接的办法。控制台「日志」页能看到每次调用的 tokens 明细，不需要自己估算。

## 4. 为什么国产能 5 折

国产模型厂商对大客户/年费订阅有阶梯价，平台把采购成本摊到用量上，再按公开挂牌价的一半零售。这是一门**薄利、靠量**的生意：折扣来自采购结构，不来自「共享号池」或「盗刷额度」，所以供给稳定、可开发票（以企业对接口径为准）。

**5 折不等于所有模型都便宜**：贵模型的绝对价格仍然高，做长上下文 RAG 时先算账再选型。

## 5. 海外模型：默认价与特价分组

海外模型分两条价轨，页面与账单上**不混写**：

| 分组 | 定价 | 供给 | SLA |
| --- | --- | --- | --- |
| **默认分组** | 官方 / OpenRouter 公开价 ×1.25 | 官方或可查价的聚合渠道 | 尽力而为，按用户协议 |
| **特价分组**（如开放） | 第三方特价渠道价加价，随渠道浮动，可低至官方价一折以下 | 第三方特价/号池类渠道 | **不承诺**，随时可能断供 |

特价分组的低价只能来自订阅额度套利、共享号池或免费额度池，共同特征是：

- **随时断供**：上游一封号，你的产品当场 500。
- **数据不可控**：请求经不透明中间方转发，留存与二次使用无从审计。
- **合规风险由调用方承担**：最终用户看到的服务主体是你。

所以对外只写「默认价 + 特价分组单列」，不把「0.0x 折」写成全站承诺；要极致低价就在控制台选特价分组，并自行准备降级路径。

## 6. 模型选择建议

| 场景 | 建议 | 理由 |
| --- | --- | --- |
| 分类、抽取、改写、客服 FAQ | `*-flash` / `*-air` 类小模型 | 单价低，延迟小，够用 |
| 复杂推理、代码生成、长文分析 | `*-pro` / 旗舰模型 | 质量优先，单次成本高但返工少 |
| 中文长文写作 | GLM / Kimi 系 | 中文语料与长上下文表现稳定 |
| 结构化输出（JSON） | 支持 `response_format` 的模型 | 少写解析兜底代码 |
| 工具调用 / Agent | 支持 `tools` 的模型 | 先小样本验证再上量 |

选型方法：固定 20–30 条真实任务做 A/B，比较「一次通过率 × 单价」，而不是只看单价。
