## 1. 一句话口径

- **国产文本**：免费档 **¥0**（`hy4flash-free`）；付费模型 = 厂商公开挂牌价 **×0.3 起**（3 折起）。
- **海外文本**：官方价 **0.49 折起**（`claude-opus-4.8`，官方 $5/$25 → 约 ¥1.80/¥9.00 每百万 tokens）；最低单价 `claude-haiku-5.5` 约 ¥0.31/¥1.56。
- **生图**：按张，**¥0.05/张起**（`gpt-image-2.6`、`gpt-image-2.5`、`gpt-image-2.6-flare`）。
- **视频**：按条或按秒，**¥2.25/条起**（`seedance-2.0-mini-5s`，¥0.45/秒 × 5 秒）；最低折扣档 `minimax-h3-6s` 约 **8 折**（¥2.40/6 秒，参考价估算）。
- 文本计价单位：**人民币 / 100 万 tokens**，输入与输出分开算。
- 最终扣费：以控制台「模型与价格」公示价与「日志」页实际用量为准；当前共 **80 个在售模型**。

## 3. 一次请求怎么算钱

```
费用 = 输入 tokens × 输入单价 + 输出 tokens × 输出单价
```

举例：`glm-5.3` 输入 2,000 tokens、输出 1,000 tokens：

```
2000 / 1,000,000 × 2.40 + 1000 / 1,000,000 × 8.40
= 0.00480 + 0.00840
= ¥0.01320
```

便宜的模型跑长文本、贵的模型跑难任务，是控制成本最直接的办法。控制台「日志」页能看到每次调用的 tokens 明细，不需要自己估算。

## 4. 为什么国产文本能 3 折

付费国产文本统一按厂商公开挂牌价的三成起零售，输入与输出同折扣；`hy4flash-free` 为本站免费档，所以 ¥0。平台按实际用量结算，不卖卡密、不处理收款；能否开票以对接口径为准。

**3 折不等于所有国产模型都便宜**：贵模型的绝对价格仍然高，做长上下文 RAG 时先算账再选型。

## 5. 海外与多模态：价格为什么能这么低

- **海外文本 0.49 折起**：按官方公开价折扣挂牌；`claude-opus-4.8` 官方 $5/$25，本站约 ¥1.80/¥9.00 每百万 tokens。最低单价是 `claude-haiku-5.5`（约 ¥0.31/¥1.56）。
- **生图 ¥0.05/张**：`gpt-image-2.6`、`gpt-image-2.5`、`gpt-image-2.6-flare` 按张计价；同档还有 ¥0.25、¥0.40、¥0.50、¥0.60、¥1.50 的型号，按质量与速度分层。
- **视频 ¥2.25/条起**：`seedance-2.0-mini-5s` 按秒计价（¥0.45/秒 × 5 秒）；最低折扣档是 `minimax-h3-6s`（¥2.40/6 秒，参考价估算约 8 折）。
- **免费模型**：`hy4flash-free` 为本站免费档，0 计费，适合做链路验证。

低价按厂商公开挂牌价折扣或免费档挂牌，具体折扣以控制台公示为准：0.49 折是当前 `claude-opus-4.8` 的公开挂牌，不是所有海外模型都 0.49 折。生产环境建议至少准备两个模型兜底，不承诺 SLA。

## 6. 模型选择建议

| 场景 | 建议 | 理由 |
| --- | --- | --- |
| 分类、抽取、改写、客服 FAQ | `*-flash` / `*-air` 类小模型 | 单价低，延迟小，够用 |
| 复杂推理、代码生成、长文分析 | `*-pro` / 旗舰模型 | 质量优先，单次成本高但返工少 |
| 中文长文写作 | GLM / Kimi 系 | 中文语料与长上下文表现稳定 |
| 结构化输出（JSON） | 支持 `response_format` 的模型 | 少写解析兜底代码 |
| 工具调用 / Agent | 支持 `tools` 的模型 | 先小样本验证再上量 |

选型方法：固定 20–30 条真实任务做 A/B，比较「一次通过率 × 单价」，而不是只看单价。
