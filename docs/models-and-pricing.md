## 1. 一句话口径

- **国产文本**：零售价 = 厂商公开挂牌价 **×0.3**（3 折）。
- **海外文本**：官方价 **1.8 折起（0.18 倍）**（示例：`gpt-6-sol` 官方 $2/$10 → 本站 ¥2.60/1M 起）。
- **生图**：按张，**¥0.05/张起**（`gpt-image-2.6-flare`）。
- **视频**：按条或按秒（官方价 5 折），**¥2.25/条起**（`seedance-2.0-mini-5s`）。
- 文本计价单位：**人民币 / 100 万 tokens**，输入与输出分开算。
- 最终扣费：以控制台「模型与价格」公示价与「日志」页实际用量为准；当前共 **80 个在售模型**。

## 3. 一次请求怎么算钱

```
费用 = 输入 tokens × 输入单价 + 输出 tokens × 输出单价
```

举例：`glm-5.3` 输入 2,000 tokens、输出 1,000 tokens：

```
2000 / 1,000,000 × 1.25 + 1000 / 1,000,000 × 4.37
= 0.00250 + 0.00437
= ¥0.00687
```

便宜的模型跑长文本、贵的模型跑难任务，是控制成本最直接的办法。控制台「日志」页能看到每次调用的 tokens 明细，不需要自己估算。

## 4. 为什么 WorkBuddy 文本能 3 折

国产文本模型来自 WorkBuddy 订阅/账号池与官方直连两条上游，平台把采购成本摊到用量上，统一按公开挂牌价的三成零售。这是一门**薄利、靠量**的生意：折扣来自采购结构，不来自「共享号池」或「盗刷额度」，所以供给稳定、可开发票（以企业对接口径为准）。

**3 折不等于所有国产模型都便宜**：贵模型的绝对价格仍然高，做长上下文 RAG 时先算账再选型。

## 5. 海外与多模态：价格为什么能这么低

- **海外文本 1.8 折起（官方价 0.18 倍）**：通过可查价的聚合渠道采购，按公开价折扣挂牌；`gpt-6-sol` 官方 $2/$10，本站 ¥2.60/1M 起。
- **生图 ¥0.05/张**：`gpt-image-2.6-flare` 走聚合特价档，按张计价；同档还有 ¥0.25、¥0.40、¥0.50 的型号，按质量与速度分层。
- **视频 ¥2.25/条起**：`seedance-2.0-mini-5s` 按秒计价（¥0.45/秒 × 5 秒），长视频按条档更贵。
- **免费模型**：`hy4flash-free` 使用上游免费额度，本站 0 计费，适合做链路验证。

低价来自采购结构（官方折扣、聚合特价、免费额度），不来自「0.0x 折」的自证式承诺：当前公开价目最低就是 1.8 折，没有 0.0x 折。低价渠道的共同风险是**随时断供、数据留存不可控、没有 SLA**——生产环境至少准备两个模型 + 一条直连官方通道，主路失败时降级。

## 6. 模型选择建议

| 场景 | 建议 | 理由 |
| --- | --- | --- |
| 分类、抽取、改写、客服 FAQ | `*-flash` / `*-air` 类小模型 | 单价低，延迟小，够用 |
| 复杂推理、代码生成、长文分析 | `*-pro` / 旗舰模型 | 质量优先，单次成本高但返工少 |
| 中文长文写作 | GLM / Kimi 系 | 中文语料与长上下文表现稳定 |
| 结构化输出（JSON） | 支持 `response_format` 的模型 | 少写解析兜底代码 |
| 工具调用 / Agent | 支持 `tools` 的模型 | 先小样本验证再上量 |

选型方法：固定 20–30 条真实任务做 A/B，比较「一次通过率 × 单价」，而不是只看单价。
