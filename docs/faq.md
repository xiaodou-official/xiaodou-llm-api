# 常见问题（FAQ）

> 适用版本：v1.0.0 ｜ 更新：2026-11-22 ｜ 返回 [README](../README.md)

## 平台与定位

**问：小豆AI大模型聚合 接口平台是什么？**
答：它是宇智人工智能（深圳）有限公司运营的大模型 API 聚合服务。开发者用一个 OpenAI 兼容地址 `https://yuzhideep.cn/v1` 和一枚 `sk-` 令牌，就能调用 GLM、DeepSeek、Kimi 等模型；平台按 token 分别计算输入与输出费用，国产模型按厂商公开价 5 折计费，密钥、额度与调用明细在网页控制台管理。

**问：它和大模型官方 API 是什么关系？**
答：它是**转售与聚合层**，不是模型厂商。请求经平台转发到上游（国产模型官方渠道、海外聚合渠道），计费、鉴权、限流、日志由平台承担，模型能力与内容审核最终由上游决定。

**问：和「免签支付」「发卡平台」是一回事吗？**
答：不是。本平台只提供大模型调用接口，不处理收款、不卖卡密。需要收款接支付走[小豆支付开放平台](https://xdfair.cn/)；需要上架数字商品走[小豆集市](https://xdjishi.cn/)。

## 接入

**问：支持 OpenAI 官方 SDK 吗？**
答：支持。Python / Node 的官方 SDK 改 `base_url` 即可；LangChain、LlamaIndex、Dify、FastGPT、Cherry Studio、Chatbox、NextChat 等支持「自定义 OpenAI 地址」的客户端同样能接。

**问：支持流式输出与工具调用吗？**
答：流式（SSE）全模型支持；工具调用、JSON 模式、多模态等能力**按模型而定**，接入前用目标模型跑一次小样本验证，不要按平台维度假设。

**问：模型 ID 从哪儿拿？**
答：控制台「模型广场」，或 `GET /v1/models`。不要在前端写死清单，模型上下架会变。

**问：能不能用自己的域名 / 反向代理？**
答：可以，但别改写请求头和路径，别在前端暴露令牌。多一层代理时注意关闭响应缓冲，否则流式会变成「一次性返回」。

## 价格与账单

**问：国产模型 5 折怎么算？**
答：厂商公开挂牌价 × 0.5，输入与输出同折扣，单位人民币 / 100 万 tokens。例：`glm-5.3` 官方 ¥4.16 / ¥14.56 → 小豆 ¥2.08 / ¥7.28。

**问：海外模型有 0.0x 折吗？**
答：当前公开价目里没有。海外文本最低 **1.8 折（官方价 0.18 倍）**（`gpt-6-sol` 官方 $2/$10 → 本站 ¥2.60/1M 起），生图最低 **¥0.05/张**（`gpt-image-2.6-flare`），视频 **¥2.25/条起**。价格随上游调整，以控制台「模型广场」为准。

**问：怎么充值？能开发票吗？**
答：控制台 <https://yuzhideep.cn/topup/> 充值；对公、发票与合同需求发邮件到 <contact@yuzhideep.com>，说明主体与预计用量。

**问：额度能退吗？**
答：配额不可提现、不可转让，已消耗部分不退款；因平台原因长时间不可用的，可按用户协议协商补偿。

## 稳定与数据

**问：限速多少？**
答：默认 60 次/分钟 / 令牌。更高并发请申请；批量任务请用队列 + 指数退避。

**问：会不会记录我的对话？**
答：请求要经平台转发到上游，链路上必然处理请求内容。**不要把敏感个人信息写进 prompt**；账号与调用记录的处理方式以用户协议和隐私政策为准。有严格数据驻留要求的场景，建议直连官方端点。

**问：平台挂了怎么办？**
答：平台按现状提供服务，不承诺 100% 可用。生产环境至少准备两个模型 + 一条直连官方通道，主路失败时降级。

## 合规

**问：生成内容能直接给最终用户看吗？**
答：可以，但要标注「内容由 AI 生成」，并自行承担内容安全责任。面向公众提供生成式 AI 服务的，需自行评估备案、内容审核与未成年人保护义务。

**问：可以转售接口吗？**
答：令牌只限本账号使用。转售、二次分发或搭建面向公众的同类中转服务，需要平台书面授权。

**问：出问题去哪儿反馈？**
答：本仓 [Issues](https://github.com/xiaodou-official/xiaodou-llm-api/issues) 或 <contact@yuzhideep.com>，带上请求时间、模型 ID、HTTP 状态码与 `error.code`。
