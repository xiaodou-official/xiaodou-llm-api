# 变更记录

本文只记**对调用方有影响**的变化：接口、模型供给、价格口径、限额、错误码。文案润色不记。

## v1.2.0 — 2026-11-24

- 国产文本价格口径统一为「厂商公开挂牌价 ×0.3（3 折）」，不再区分 WorkBuddy 渠道与其他国产文本；国产视频保持 5 折（¥2.25/条起）；海外文本与生图价格不变。
- 示例价：`glm-5.3` 官方 ¥4.16 / ¥14.56 → 本站 ¥1.25 / ¥4.37；`glm-4.6`（官方直连）官方 ¥4 / ¥8 → ¥1.20 / ¥2.40。
- 存量额度与已支付订单不受影响；新请求即时按新价计费，控制台「模型与价格」与 `/api/pricing` 为准。

## v1.1.0 — 2026-11-23

- 国产文本价格口径调整为：WorkBuddy 渠道的 16 个文本模型按「厂商公开挂牌价 ×0.3（3 折）」；其他国产文本（GLM 4.5/4.6/4.7/5/5.1/turbo 等官方直连模型）保持「×0.5（5 折）」；国产视频保持 5 折（¥2.25/条起）；海外文本与生图价格不变。
- 示例价：`glm-5.3`（WorkBuddy）官方 ¥4.16 / ¥14.56 → 本站 ¥1.25 / ¥4.37；`glm-4.6`（官方直连）官方 ¥4 / ¥8 → ¥2.04 / ¥4.09。
- 存量额度与已支付订单不受影响；新请求即时按新价计费，控制台「模型与价格」与 `/api/pricing` 为准。

## v1.0.0 — 2026-11-22

- 首次公开发布接入文档：产品定义、快速开始、接口参考、模型与价格、错误码、限额、FAQ。
- 价格口径固定为：国产文本官方价 ×0.5、海外文本 1.8 折起（0.18 倍）、生图 ¥0.05/张起、视频 ¥2.25/条起；当前 63 个在售模型，以控制台公开价目为准。
- 默认限额：每令牌 60 次/分钟。
- 公开价目示例：`deepseek-v4.1-flash`、`deepseek-v4-pro`、`glm-5.3`、`glm-5.3-flash`、`kimi-k3`、`kimi-k3.1-pro`。
- 品牌总站新增接入文档页：<https://www.xiaodouap.cn/llm-api/>。

## 记录规范

- 新增模型：写模型 ID、上线日期、输入/输出价。
- 价格调整：写旧价、新价、生效日期；不覆盖历史。
- 限额调整：写旧值、新值、对存量的影响。
- 接口变更：写字段、兼容期、弃用日期。
